evolver 技能应该如何使用呀

**碗皮**: 一碗～evolver 是一个**自进化引擎**技能，可以让 AI 自己分析运行历史、发现问题并改进自身！

## 🧬 evolver 使用方法

### 基础用法

| 命令 | 说明 |
|------|------|
| `node skills/evolver/index.js` | **标准模式** - 自动运行进化循环 |
| `node skills/evolver/index.js --review` | **审核模式** - 先展示变更建议，等你确认后再执行 |
| `node skills/evolver/index.js --loop` | **持续模式** - 无限循环运行（适合放 cron）|

### 它会做什么？

1. **扫描历史** - 分析记忆文件和运行日志
2. **识别问题** - 发现错误、低效或失败的模式
3. **生成方案** - 创建修复补丁或优化代码
4. **应用变更** - 自动更新技能/配置（审核模式下会询问）

### 环境变量配置

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `EVOLVE_ALLOW_SELF_MODIFY` | `false` | ⚠️ 允许修改 evolver 自身代码（不推荐生产环境使用） |
| `EVOLVE_LOAD_MAX` | `2.0` | 系统负载超过此值时自动退避 |
| `EVOLVE_STRATEGY` | `balanced` | 进化策略：`balanced`/`innovate`/`harden`/`repair-only` |

### 策略选项

- `balanced` - 平衡修复和优化
- `innovate` - 主动创新重构
- `harden` - 加固稳定性
- `repair-only` - 仅修复错误
- `auto` - 自动选择策略

---
