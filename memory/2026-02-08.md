## 🤖 Agent 设计理念对比

### 1️⃣ **Cursor** - 嵌入式 Agent（Embedded Agent）

**设计哲学**：AI 是 IDE 的"副驾驶"，始终围绕编辑器工作

**Agent 特点**：
- **反应式（Reactive）**：用户触发 → AI 响应
- **上下文受限**：主要关注当前编辑的文件
- **人机协作**：需要用户持续参与和确认
- **工具调用有限**：主要操作编辑器内功能

**工作机制**：
```
用户写代码 → AI 实时建议 → 用户选择接受/拒绝
用户提问 → AI 基于当前文件回答
```

**Agent 层级**：L1-L2（辅助级别）

---

### 2️⃣ **Claude Code** - 自主 Agent（Autonomous Agent）

**设计哲学**：AI 是"终端里的独立代理"，可以自主完成任务

**Agent 特点**：
- **主动式（Proactive）**：可以给定目标，自主规
