## TTRPG 跑团存档使用约定 ✅

**生效日期:** 2026-02-13
**约定:** 下次跑团记得使用 ttrpg_manager 技能

### 使用流程
每次跑团时：
1. **开始前** → 读取存档：`python3 scripts/ttrpg_manager.py status "战役名"`
2. **进行中** → 用 TTRPG GM 技能主持游戏
3. **结束后** → 记录会话：`python3 scripts/ttrpg_manager.py log "战役名" "发生的事..."`

### 主动提醒
- 当一碗说"跑团"、"继续游戏"、"TTRPG"时，先检查是否有存档
- 如果有存档，先读取进度再继续
- 如果没有存档，询问是否创建新战役
