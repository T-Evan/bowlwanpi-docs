## 🔄 存档管理命令

```bash
# 创建新战役
python3 scripts/ttrpg_manager.py new [战役名] [世界观]

# 记录会话
python3 scripts/ttrpg_manager.py log [战役名] "发生的事"

# 查看当前进度
python3 scripts/ttrpg_manager.py status [战役名]

# 列出所有存档
python3 scripts/ttrpg_manager.py list

# 恢复/继续战役
python3 scripts/ttrpg_manager.py resume [战役名]
```
