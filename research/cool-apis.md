# 🎮 GitHub 上好玩的 API 推荐

## 📊 数据 & 信息类

### 1. 天气预报 API
- **Open-Meteo** (免费，无需API Key)
- 功能：全球天气预报、历史天气数据
- 用途：每日天气推送、出行提醒
- 网址：https://open-meteo.com/

### 2. 汇率 API
- **ExchangeRate-API** (免费版)
- 功能：实时汇率转换
- 用途：海淘价格监控、投资参考
- 网址：https://www.exchangerate-api.com/

### 3. 股票/加密货币 API
- **Alpha Vantage** (免费版)
- 功能：股票数据、技术指标
- 用途：股价监控、投资组合跟踪
- 网址：https://www.alphavantage.co/

## 🎨 娱乐 & 趣味类

### 4. 随机名言 API
- **Quotable** (免费)
- 功能：随机名言、按作者/标签筛选
- 用途：每日一句、励志推送
- 示例：GET https://api.quotable.io/random

### 5. 猫咪图片 API

## 🛠️ 实用工具类

### 9. 短链接 API
- **CleanURI** (免费)
- 功能：长链接转短链接
- 用途：分享链接优化
- 示例：POST https://cleanuri.com/api/v1/shorten

### 10. URL 预览 API
- **LinkPreview** (免费版)
- 功能：获取网页标题、描述、图片
- 用途：链接卡片生成、内容预览
- 网址：https://www.linkpreview.net/

### 11. QR Code API
- **QRServer** (免费)
- 功能：生成二维码
- 用途：快速生成分享二维码
- 示例：GET https://api.qrserver.com/v1/create-qr-code/?data=xxx

### 12. 翻译 API
- **LibreTranslate** (免费)
- 功能：多语言翻译
- 用途：外文内容翻译
- 网址：https://libretranslate.com/
