# OpenClaw 会话 Hooks

## 实时存储已启用

### before_response.py
- **触发时机**: 收到用户消息后、生成回复前
- **功能**: 从三记忆系统检索相关记忆
- **输出**: 提供上下文给回复生成

### after_response.py  
- **触发时机**: 生成回复后、发送给用户前
- **功能**: 存储对话到三记忆系统
- **存储位置**:
  - ✅ memU (云端)
  - ✅ Hippocampus (本地)
  - ✅ MemOS (MCP)
  - ✅ 每日记忆文件 (memory/YYYY-MM-DD.md)
