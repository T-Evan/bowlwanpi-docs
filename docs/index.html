快速部署 (5分钟)

1️⃣ 基础环境

pip3 install memu-sdk crawl4ai
2️⃣ 恢复工作区
mkdir -p ~/.openclaw/workspace
cd ~/.openclaw/workspace
git clone <仓库地址> .
3️⃣ 配置凭证
mkdir -p secrets/
# 放置凭证文件
# memu-credentials.json
# tencent-credentials.json
4️⃣ 启动服务
sudo systemctl start mihomo
openclaw gateway start
openclaw cron list

故障排查

问题 排查步骤 解决方案
记忆同步失败 检查 memu-credentials.json 更新API Key
搜索无结果 检查腾讯云凭证 确认SecretId/Key有效
TTS失败 检查豆包凭证 更新.env文件
定时任务不执行 检查cron日志 确认权限和路径
MCP连接失败 检查mcp_config.json 验证配置格式
