故障排查

问题 排查步骤 解决方案
记忆同步失败 检查 memu-credentials.json 更新API Key
搜索无结果 检查腾讯云凭证 确认SecretId/Key有效
TTS失败 检查豆包凭证 更新.env文件
定时任务不执行 检查cron日志 确认权限和路径
MCP连接失败 检查mcp_config.json 验证配置格式
