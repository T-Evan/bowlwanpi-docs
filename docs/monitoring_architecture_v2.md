## 🔄 整合优化说明

### 1. 统一状态报告 (每30分钟)

**优化内容:**
- ✅ 修复数据采集 bug
- ✅ 增加错误处理
- ✅ 服务检测带重试机制

**职责:**
- 快速展示系统状态
- 及时发现问题
- 简洁的通知格式

### 2. 深度自检与修复 (每小时)

**新增功能:**
- 🆕 自动检测 Gateway/Mihomo 故障
- 🆕 自动重启故障服务
- 🆕 日志错误分析
- 🆕 报告完整性验证

**职责:**
- 深度检查系统健康
- 自动修复常见问题
- 生成详细报告

### 3. 安全扫描 (每周)

**保持不变:**
- 每周日凌晨 3:00
- 全面的安全审计

## 📋 定时任务配置

### OpenClaw 配置

```json
{
  "jobs": [
    {
      "name": "统一状态报告",
      "schedule": "*/30 * * * *",
      "command": "heartbeat_unified.sh"
    },
    {
      "name": "深度自检与修复", 
      "schedule": "0 * * * *",
      "command": "cron_self_check.sh"
    },
    {
      "name": "安全扫描",
      "schedule": "0 3 * * 0",
      "command": "security_cron.sh"
    }
  ]
}
```

### Linux 系统级 Cron (兜底)

```cron
# 统一状态报告 - 每30分钟
*/30 * * * * root heartbeat_unified.sh

# 深度自检与修复 - 每小时
0 * * * * root cron_self_check.sh

# 安全扫描 - 每周日
0 3 * * 0 root security_cron.sh
```

## 🚀 优势

1. **层次分明**
   - 快速报告：30分钟，及时了解状态
   - 深度自检：1小时，全面检查和修复
   - 安全扫描：1周，专业安全审计

2. **避免重复**
   - 每个层级职责清晰
   - 不重复发送相同内容
   - 减少通知轰炸

3. **自动修复**
   - 深度自检带自动修复
   - 减少人工干预
   - 提高系统可用性

4. **兜底保障**
   - OpenClaw + Linux cron 双保险
   - 即使一层失效，另一层继续工作
