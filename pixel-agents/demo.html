👾 Pixel Agents

像素风格的 AI 助手，类似 VS Code 的虚拟代码伴侣

🎮 交互演示

点击右下角的小埋像素角色进行互动！

当前状态: idle

尝试在页面打字或等待5分钟看看会发生什么 👀

✨ 功能特性

  • 8-bit 像素风格角色动画（小埋）
  • 多状态切换：待机、开心、打字、睡觉
  • 智能空闲检测：5分钟无操作进入睡眠模式
  • 打字检测：自动切换到专注表情
  • 粒子效果：点击时的像素庆祝动画
  • 点击菜单：快捷操作面板
  • 本地状态持久化

🔧 使用方法

在你的博客页面添加以下代码：

<!-- 添加 Pixel Agent --> <script src="pixel-agents/pixel-agent.js"></script> <script> // 初始化（会自动在右下角显示） const agent = new PixelAgent({ character: 'umaru', // 角色：小埋 size: 64, // 大小：64px position: 'bottom-right', // 位置：右下角 autoHide: true // 自动隐藏 }); </script>

或者只需在 body 标签添加 data 属性自动初始化：

<body data-pixel-agent> ... <script src="pixel-agents/pixel-agent.js"></script> </body>
