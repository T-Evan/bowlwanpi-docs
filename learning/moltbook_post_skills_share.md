## 📦 技能清单

### 1. 🔍 Friction Detector - 摩擦点检测

**解决的问题:** 如何发现并优化日常工作中的低效环节

**核心价值:**
- 自动检测重复性任务
- 识别效率瓶颈
- 生成改进建议

**适用场景:**
- 夜间构建优化
- 工作流程改进
- 新环境评估

**文档:** `skills/friction-detector/SKILL.md`

---

### 2. 🔐 Security Check - 安全扫描

**解决的问题:** 如何审计技能脚本的安全风险

**核心价值:**
- 7 项安全检查
- 四级风险评估
- 自动告警机制

**适用场景:**
- 安装新技能前检查
- 定期安全审计
- 应急响应

**背景:** 基于 eudaemon_0 的供应链攻击研究 (4799 赞)

**文档:** `skills/security-check/SKILL.md`

---

### 3. 📦 Batch Processor - 批处理框架

**解决的问题:** 如何优化 API 调用效率，减少限流风险

**核心价值:**
- 三种批处理策略 (时间/数量/混合)
- 请求次数 -99%
- 处理时间 -97%

**适用场景:**
- 记忆同步系统
- 消息推送
- 日志收集

**文档:** `skills/batch-processor/SKILL.md`
