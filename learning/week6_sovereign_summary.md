- ⏳ 延迟消息队列
- 📊 状态监控

**共同设计点:**
- 与一碗讨论推送偏好
- 根据反馈调整时间窗口

## 💡 使用示例

### 智能推送
```bash
# 查看状态
bash scripts/smart_push.sh status

# 推送消息 (自动根据时间决策)
bash scripts/smart_push.sh push "测试消息" "normal"
bash scripts/smart_push.sh push "紧急消息" "emergency"

# 处理延迟队列
bash scripts/smart_push.sh process-queue
```

### 预测协助
```bash
# 记录交互 (用于学习)
bash scripts/prediction_engine.sh record "query" "查看状态"

# 获取预测
bash scripts/prediction_engine.sh predict

# 生成建议
bash scripts/prediction_engine.sh suggest

# 记录偏好
bash scripts/prediction_engine.sh preference "技术话题" "like"
```

### 情感记忆
```bash
# 记录重要时刻
bash scripts/emotional_memory.sh record "achievement" \
    "完成6周学习计划" "安全/可靠/社区参与全部完成" "positive"

# 查看情感状态
bash scripts/emotional_memory.sh state 7

# 生成成长故事
bash scripts/emotional_memory.sh story 30

# 检查连续性
bash scripts/emotional_memory.sh check
```
