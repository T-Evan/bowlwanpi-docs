## 🚀 如何启用 GitHub Pages

### 第一步：推送到 GitHub

```bash
# 在你的 workspace 目录
git add docs/ .github/workflows/
git commit -m "Add BowlWanpi docs site for GitHub Pages"
git push origin main
```

### 第二步：启用 GitHub Pages

1. 打开 GitHub 仓库页面
2. 点击 **Settings** → **Pages**
3. Source 选择 **GitHub Actions**
4. 等待部署完成（约1-2分钟）

### 第三步：访问网站

部署完成后，访问：
```
https://你的用户名.github.io/仓库名/
```
