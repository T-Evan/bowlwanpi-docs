# 🧠 memU 记忆系统

## 功能概述

这个 skill 让 BowlWanpi 拥有了**持久记忆能力**：

- 💾 **自动存储**：重要对话自动保存到 memU
- 🔍 **智能检索**：回答前检索相关历史记忆
- 📊 **用户画像**：维护一碗的偏好和习惯
- 🎯 **意图预测**：基于记忆预测下一步需求

## 工作原理

### 1. 记忆存储
每次对话后，系统会自动判断：
- 是否包含重要信息？
- 是否是用户的偏好/习惯？
- 是否需要长期记住？

如果是，自动存储到 memU 云端记忆库。

### 2. 记忆检索
每次收到消息时，系统会：
- 检索与当前话题相关的历史记忆
- 将相关记忆注入系统提示
- 让回复更有上下文感

### 3. 记忆增强回复
示例：
```
一碗：我想喝茶

[系统检索到记忆]
💭 相关记忆：
1. 一碗喜欢喝绿茶（2026-02-07）

[碗皮回复]
🥣 好呀～我记得你喜欢绿茶，要我帮你查查现在的茶叶推荐吗？
```

## 使用方法

无需手动操作，系统全自动运行。

### 手动管理命令（未来支持）
- `/memory on` - 开启记忆
- `/memory off` - 关闭记忆
- `/memory forget <内容>` - 删除特定记忆
- `/memory summary` - 查看记忆摘要

## 技术细节

**后端服务**：memU (https://memu.pro/)
**存储方式**：云端加密存储
**检索算法**：语义相似度匹配
**隐私保护**：敏感信息自动过滤

## 配置

环境变量：
```bash
export MEMU_API_KEY="your_api_key"
export MEMU_BASE_URL="https://api.memu.pro/v1"
```
