# 一分钟新闻 (One Minute News)

快速新闻摘要推送技能，聚合多源新闻，1分钟快速浏览今日要闻。

## 功能

- 📰 聚合科技、财经、国际等多个领域新闻
- ⏱️ AI 智能摘要，每条新闻控制在 1-2 句话
- 🔄 支持定时推送（默认每天早上 8:00）
- 📱 适配飞书消息格式

## 使用方法

### 手动生成今日新闻

```bash
cd ~/.openclaw/workspace/skills/one-minute-news
python3 scripts/generate.py
```

### 定时推送

已配置 cron 任务，每天早上 8:00 自动推送。

## 新闻源

| 分类 | 来源 |
|------|------|
| 🚀 科技 | 36氪、虎嗅、TechCrunch |
| 💰 财经 | 华尔街见闻、财新 |
| 🌍 综合 | BBC中文、Reuters |

## 输出格式示例

```
📰 一分钟新闻 | 2026-02-09

🚀 科技
  1. OpenAI 发布 GPT-4.5 预览版
  2. 苹果 iOS 18.4 将集成更多 AI 功能
  3. 英伟达财报超预期，股价大涨

💰 财经
  1. 比特币突破 10 万美元
  2. 美联储暗示可能暂停加息

🌍 综合
  1. 特朗普宣布新关税政策
  2. 欧盟通过芯片补贴法案

⏱️ 共 7 条快讯
```

## 配置文件

`config.json` - 可自定义新闻源和推送时间

## 依赖

- Python 3.8+
- feedparser (RSS 解析)

安装依赖：
```bash
pip install feedparser
```
