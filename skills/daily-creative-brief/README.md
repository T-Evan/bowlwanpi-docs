# Daily Creative Brief 🎨

每日创意简报生成器 - 系统提升 AI 助手创造力

## ✨ 功能特性

### 核心功能
| 功能 | 描述 |
|------|------|
| 🧠 **记忆挖掘** | 从历史记录中提取灵感线索 |
| 📊 **趋势分析** | 分析工具更新、知识库增长等趋势 |
| 🎯 **挑战生成** | 每天生成一个创造任务 |
| ✍️ **内容创作** | 自动生成可分享的社交媒体内容 |
| 🎮 **成长追踪** | 记录完成情况，获得经验值 |

### 🔥 智能扩展 (新!)
| 功能 | 描述 |
|------|------|
| 🎯 **智能推荐** | 基于历史偏好个性化推荐挑战类型 |
| 📊 **周报告** | 自动汇总一周创造成果和徽章 |
| 🧠 **AI Brain集成** | 根据动力状态自动调整难度 |
| ⚡ **快速工具** | 快速记录灵感/代码/笔记/推文 |

## 🚀 快速开始

### 1. 生成每日创意简报
```bash
cd ~/.openclaw/workspace/skills/daily-creative-brief
python3 scripts/generate_brief.py
```

### 2. 查看创造追踪面板
```bash
python3 scripts/dashboard.py
```

### 3. 快速创造工具
```bash
# 记录灵感
python3 scripts/quick_create.py idea "突然想到可以..."

# 保存代码片段
python3 scripts/quick_create.py snippet "快速排序" "def sort(arr):..." python

# 生成社交媒体内容
python3 scripts/quick_create.py tweet "今天学到了..." "#AI,#学习"

# 收藏链接
python3 scripts/quick_create.py link "https://example.com" "好文章"
```

### 4. 记录完成情况
```bash
python3 scripts/log_creation.py "完成了XX任务"
```

### 5. 智能挑战推荐 (新!)
```bash
# 根据你的历史偏好和动力状态推荐挑战
python3 scripts/recommender.py
```

### 6. 生成周报告 (新!)
```bash
# 生成本周创造报告
python3 scripts/weekly_report.py

# 生成上周报告
python3 scripts/weekly_report.py last
```

### 7. AI Brain 同步 (新!)
```bash
# 同步AI Brain状态，获取个性化建议
python3 scripts/brain_sync.py

# 完成任务后更新Brain
python3 scripts/brain_sync.py update [任务类型] [难度]
```

### 8. 定时自动运行
已配置每天 9:00 自动生成简报并发送

## 📋 创造挑战类型

1. **技能开发** - 开发一个微型工具
2. **内容创作** - 写一篇技术微分享  
3. **自动化** - 自动化一个重复任务
4. **探索** - 尝试一个新工具
5. **优化** - 让现有流程快一倍
6. **创意写作** - 用故事讲技术
